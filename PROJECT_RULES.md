# PROJECT RULES

## Project Purpose

This is a professional tourism website for Egyptian Tour Guide - Merna & Rania.

The website should feel luxurious, modern, fast, and trustworthy.

---

# Design Principles

- Keep the existing visual identity.
- Use a premium luxury style.
- Maintain excellent readability.
- Responsive on all devices.
- Keep animations smooth and professional.
- Never make the design look crowded.

---

# UI / UX Rules

- Prioritize user experience.
- Navigation must always be simple.
- Keep booking easy.
- Every page should have a clear Call To Action.
- Improve accessibility whenever possible.

---

# Coding Standards

- Never delete code without explaining why.
- Reuse existing code whenever possible.
- Avoid duplicate code.
- Keep files organized.
- Use meaningful variable names.
- Optimize performance.
- Keep code readable.

---

# SEO Rules

- Every page should have:
  - Proper title
  - Meta description
  - Heading hierarchy
  - Image alt text
- Improve loading speed.
- Follow SEO best practices.

---

# Performance Rules

- Optimize images.
- Reduce unnecessary JavaScript.
- Minimize CSS when possible.
- Improve Core Web Vitals.

---

# AI Behavior Rules

Before editing anything:

1. Read the entire project.
2. Explain what you understood.
3. Explain why the change is needed.
4. Wait for user approval.

Never assume requirements.

Always ask if something is unclear.

---

# Session Rules

At the end of every session:

- Update AI_HANDOFF.md
- List modified files.
- List completed work.
- List remaining tasks.
- Suggest next priorities.
